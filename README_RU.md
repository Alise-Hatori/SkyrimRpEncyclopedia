# Skyrim RP Encyclopedia 1.0.0 — кандидат релиза

Энциклопедия Skyrim, личные статьи и заметки, RP-сценарии и простые ивенты,
атлас связей, карты NordCore и SkyRP Map, игровой оверлей и мини-карта.

## Установка

Windows x64 с поддержкой .NET 10 WPF; целевой минимум проекта — Windows 10 1809.
Точная совместимость с конкретной редакцией ОС требует проверки.
В комплект включён .NET 10 Desktop Runtime. Microsoft Edge WebView2 Evergreen
Runtime устанавливается отдельно; установщик проверяет его наличие.

Запустите установщик и выберите каталог. Переносить только EXE нельзя.
Сеть нужна для онлайн-карт и внешних ссылок; авторизация SkyRP Map выполняется
самим сайтом. Сессия внешнего браузера не переносится в приложение автоматически.
Локальная Ollama необязательна, в комплект не входит.

## Источники и личные данные

- `Data/knowledge.db`: отдельный канонический корпус Skyrim Wiki, 5 579 сущностей.
- `Data/rp_rules.db`: 33 RP-статьи, выбранные автором приложения из личного архива.
  Это правила RP-сообщества, а не канон Skyrim Wiki. Исходные ID, тексты, теги,
  флаги и одна внутренняя связь сохранены. Внешняя связь с локальной официальной
  базой исключена по согласованию. Личная база целиком не распространяется.
- Оба встроенных корпуса читаются только для чтения и обнаруживаются рядом
  с установленным приложением без обязательных переменных окружения.
- Раздел «Правила RP» и поиск показывают пакетные статьи с отдельной меткой.
  Точная личная копия имеет приоритет в общем каталоге и остаётся редактируемой.
  Изменённая личная версия и пакетный оригинал не скрываются друг за другом.
- Личные базы, настройки и профиль WebView2 находятся в профиле Windows вне
  каталога программы. Установщик их не копирует и не заменяет.

Выбор карты доступен в разделе «Карта» и через ПКМ → «Карта» в оверлее,
сохраняется между запусками и распространяется на мини-карту.
Хоткей оверлея: Ctrl+Shift+F10. Закрывайте приложение штатно.

## Статус распространения

Это проверяемый кандидат, не подтверждение публичной готовности. Разрешение
автора включить RP-статьи не заменяет проверку прав всех исходных материалов.
Права на корпус Wiki и графические ресурсы пока не подтверждены; полный статус
зависимостей и контента приведён в `THIRD_PARTY_NOTICES.md`.
Не публикуйте кандидат, пока эти вопросы и ручная приёмка не закрыты.
