# Skyrim RP Encyclopedia: внутренняя тестовая сборка

> Историческая инструкция для прежнего framework-dependent комплекта. Текущий
> кандидат — self-contained x64 с двумя отдельными базами. Актуальные условия
> установки и ограничения приведены в README.md и docs/RELEASE_NOTES_1.0.0.md.

Приложение для чтения энциклопедии Skyrim, личных материалов, заметок,
RP-ивентов и сценариев. Этот комплект не является принятым публичным релизом 1.0.
Базы знаний и пользовательские данные в него не включены.

## Требования и установка

- Windows с поддержкой .NET 10 WPF; целевой минимум проекта — Windows 10 1809.
  Реальная совместимость с конкретной версией Windows требует отдельной проверки.
- .NET 10 Desktop Runtime соответствующей архитектуры. Один только ASP.NET Runtime
  или обычный .NET Runtime не заменяет Desktop Runtime.
- Microsoft Edge WebView2 Runtime для карты. Он не встроен в комплект.
- Распакуйте весь каталог приложения в доступную папку, сохранив `runtimes` и DLL.
  Запустите `SkyrimRpEncyclopedia.exe`. Не переносите только EXE.

Не удаляйте DLL и каталог `runtimes`: они нужны загрузчику даже при установленном
.NET Desktop Runtime. Перед запуском проверьте комплект из его каталога:
`pwsh -NoProfile -File .\Scripts\Test-ReleasePackage.ps1 -PackagePath .`.
Проверка только читает файлы; при ошибке используйте заново полный опубликованный
каталог, не восстанавливайте и не пересоздавайте пользовательские базы.

Установка необходимых runtime пользователем — отдельное действие. Приложение не
устанавливает их автоматически. Проверка без Visual Studio на чистой Windows ещё
не выполнена. Текущий комплект — framework-dependent для среды публикации.

## Базы и первый запуск

Личные и официальные данные по умолчанию находятся в
`%LOCALAPPDATA%\SkyrimRpEncyclopedia\user.db` и `official.db`.
Если файла нет, штатный сервис создаёт новую базу; существующую чужую или
повреждённую базу запуск не заменяет и не восстанавливает автоматически.
Не указывайте Raw или Knowledge DB вместо пользовательской/официальной базы.

Порядок выбора Knowledge DB:

1. Явный путь, переданный сервису программно (если такой вызов используется).
2. Переменная процесса `SKYRIM_RP_MVP_DB`.
3. Существующий `Data\knowledge.db` рядом с приложением.

Knowledge DB открывается только для чтения. Не заданный путь не вызывает загрузку
или создание корпуса. Неверный явный путь не подменяется другим файлом. Если
корпус недоступен, показывается диагностика; личные материалы остаются доступны,
если их базы исправны. Поддерживаемые Knowledge/MVP корпуса имеют схему 2.6.

Подключайте только законно полученный совместимый корпус. Комплект не скачивает
и не копирует базу из временного каталога разработчика. Пользователь самостоятельно
выбирает постоянный путь и обеспечивает необходимые права на контент.

## Безопасная ручная проверка

В PowerShell из каталога комплекта (замените путь к базе своим существующим файлом):

```powershell
$knowledgePath = Read-Host 'Полный путь к существующей Knowledge DB'
if (!(Test-Path -LiteralPath $knowledgePath -PathType Leaf)) { throw 'База не найдена' }
$isolatedDirectory = Join-Path ([IO.Path]::GetTempPath()) ('SkyrimRP_ReleaseTest_' + [Guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $isolatedDirectory | Out-Null
$testStart = [Diagnostics.ProcessStartInfo]::new((Join-Path $PWD 'SkyrimRpEncyclopedia.exe'))
$testStart.UseShellExecute = $false
$testStart.WorkingDirectory = $PWD.Path
$testStart.Environment['SKYRIM_RP_MVP_DB'] = [IO.Path]::GetFullPath($knowledgePath)
$testStart.Environment['SKYRIM_RP_USER_DB'] = Join-Path $isolatedDirectory 'user.db'
$testStart.Environment['SKYRIM_RP_OFFICIAL_DB'] = Join-Path $isolatedDirectory 'official.db'
[Diagnostics.Process]::Start($testStart)
```

Переменные задаются только дочернему процессу. Рабочие базы не копируются.
Закрывайте окно штатной кнопкой закрытия; не завершайте процесс принудительно.
Не запускайте второй экземпляр с теми же тестовыми путями. Повторный запуск с тем
же `$testStart` позволяет проверить сохранность тестовых материалов.
Диагностический журнал по-прежнему использует общий путь LocalAppData (не базы).

## Основные действия

- Каталог: поиск, категории, открытие статьи и возврат. Заголовок, запрос и
  положение каталога восстанавливаются при возврате.
- Фильтры: источник, категория, все выбранные теги и все выбранные флаги.
  Значения отмечены источником; выбор несовместимых источников даёт пустой результат.
  Сопоставление тегов/флагов точное, а не по подстроке.
- История: успешно открытая статья записывается в личную базу; ошибка истории не
  закрывает статью. Корпус знаний от этого не изменяется.
- Личные статьи и заметки: запись только в пользовательскую базу. При отказе
  сохранения форма остаётся открытой. Исправьте причину и повторите вручную.
- Конструктор ивентов и библиотека: сохранение, открытие для редактирования,
  обновление и удаление. Повторное сохранение текущего ивента обновляет его.
  «Новый ивент / Очистить» начинает новый черновик.
- Генератор простых ивентов: тематика, длительность, seed; обычная генерация и
  точное повторение. Публичный текст и заметки ведущего копируются отдельно.
  Этот экран не сохраняет события в базу и не экспортирует JSON.
- Генератор сценариев: жанр, параметры, seed, проверка и JSON. Предложенные
  канонические опоры не равны подтверждённым; вымысел и гипотезы отделены от канона.
- Атлас знаний: исследование или полная карта, выбор источника, связи и открытие
  статьи. `Related` не доказывает союз, вражду, мотив или причинность.
- Оверлей, карта и мини-карта сохраняют прежние механизмы. Онлайн-карта и действия
  открытия внешних URL могут использовать сеть; для офлайн-приёмки их не вызывайте.
- ИИ-помощник необязателен: текущие defaults Ollama `qwen3:8b`,
  `http://127.0.0.1:11434/api/generate`. Переменные `SKYRIM_RP_OLLAMA_MODEL` и
  `SKYRIM_RP_OLLAMA_ENDPOINT` могут их изменить. Генерация требует доступной модели;
  наличие раздела не означает, что модель установлена. В релизных проверках
  реальный вызов модели не выполнялся.

## Ошибки и сохранность данных

При ошибке запуска проверьте выбранные пути, доступ к файлам и целостность базы.
Не удаляйте свои базы для устранения ошибки и не подменяйте их пустыми файлами.
Журнал: `%LOCALAPPDATA%\SkyrimRpEncyclopedia\overlay-crash-diagnostics.log`.
Перед передачей журнала проверьте его на личные пути/содержимое ошибок.
Резервное копирование пользовательских файлов выполняйте после штатного закрытия
приложения с сохранением необходимых SQLite sidecar-файлов, если они остались.

## Формат распространения

Выбран framework-dependent каталог: меньше размер, используются уже восстановленные
зависимости, runtime обновляется отдельно. Альтернатива self-contained больше и
потребует отдельной подготовки runtime-пакетов/проверки архитектуры; сейчас не
публиковалась. Ни один вариант не включает автоматически WebView2 Runtime или
права на контент. Профиль: `Properties\PublishProfiles\LocalFramework.pubxml`.

Из исходников, при уже восстановленных зависимостях, локально без восстановления:

```powershell
dotnet publish .\SkyrimRpEncyclopedia.csproj -c Release --no-restore -p:PublishProfile=LocalFramework -o "$env:TEMP\SkyrimRP_LocalRelease"
```

Используйте новый пустой каталог вывода, не существующую установку или папку данных.
Для публичного выпуска сначала выполните `RELEASE_CHECKLIST.md` и закройте вопросы
из `THIRD_PARTY_NOTICES.md`.
