# Энциклопедия Skyrim RP

## [⬇ Скачать Энциклопедию Skyrim RP для Windows x64](https://github.com/Alise-Hatori/SkyrimRpEncyclopedia/releases)

> **Статус:** релиз 1.0.0 NC подготовлен, но пока не опубликован. Репозиторий остаётся приватным. Общедоступное скачивание станет возможным после публикации релиза и изменения видимости репозитория.

**Энциклопедия Skyrim RP** — настольная энциклопедия и набор инструментов для ведущих и участников Skyrim RolePlay. Программа объединяет справочные статьи, RP-правила, интерактивные карты и генераторы игровых событий. Она позволяет обращаться к знаниям о Тамриэле и готовить ролевые ситуации в одном приложении.

Для обычной установки не нужны Visual Studio, Git, .NET SDK, командная строка или ручная сборка.

## Возможности

- **Энциклопедия:** поиск и чтение статей, категории, связи между материалами и «Атлас знаний».
- **Личные материалы:** собственные статьи, заметки, теги и флаги.
- **RP-правила:** отдельная база из 33 статей сообщества — это материалы для ролевой игры, а не канон The Elder Scrolls Wiki.
- **Генераторы:** офлайн-генерация RP-сценариев и простых игровых событий без языковой модели и сетевых запросов. Результат можно повторить по семени.
- **Интерактивные карты:** [NordCore](https://map.nordcore.dev/) и [SkyRP Map](https://skyrpmap.com/).
- **Игровой интерфейс:** оверлей и отдельное окно мини-карты для удобного обращения к материалам рядом с игрой.

ИИ-помощник на базе локальной Ollama — необязательная функция. Ollama и языковая модель не входят в установщик и не требуются для чтения статей или работы офлайн-генераторов.

## Установка

1. Откройте [страницу релизов](https://github.com/Alise-Hatori/SkyrimRpEncyclopedia/releases).
2. В опубликованном релизе разверните раздел **Assets** и скачайте `SkyrimRP-Setup-1.0.0.exe`. Не выбирайте `Source code (zip)` или `Source code (tar.gz)` — это архивы исходного кода, а не установщик.
3. Запустите скачанный файл, ознакомьтесь с условиями лицензии и выберите каталог установки.
4. Завершите установку и запустите приложение через созданный ярлык.

Установщик содержит приложение и обе базы данных. Для обычной установки не нужно отдельно скачивать `knowledge.db.zip` или `rp_rules.db`.

### Системные требования и подключение

- **ОС:** Windows x64. Проект ориентирован на Windows 10 версии 1809 (сборка 17763) и новее; совместимость со всеми редакциями Windows отдельно не подтверждена.
- **.NET:** .NET 10 Desktop Runtime включён в установщик приложения.
- **WebView2:** установщик включает официальный Microsoft Edge WebView2 Evergreen Standalone Runtime 155.0.4283.62 x64 и устанавливает его, если необходимый Runtime отсутствует. Уже установленный Runtime не заменяется принудительно.
- **Интернет:** нужен для онлайн-карт, авторизации на внешних сайтах и переходов по внешним ссылкам. Чтение встроенных статей и офлайн-генераторы работают без сети.

Установщик не подписан сертификатом издателя, поэтому Windows SmartScreen или антивирус могут показывать предупреждения. Перед запуском проверяйте источник файла и контрольную сумму; не отключайте защиту только ради установки.

## Данные и резервное копирование

В комплект входят две отдельные базы:

- **База знаний:** 5 579 сущностей из русской The Elder Scrolls Wiki.
- **База RP-правил:** 33 статьи ролевого сообщества.

Встроенные базы используются приложением в режиме чтения. Личная база `user.db`, история, логи, cookies и профиль WebView2 не включены в установочный комплект.

Перед обновлением или переустановкой закройте приложение и создайте резервную копию пользовательских данных. Профиль WebView2 и настройки хранятся отдельно от файлов программы и намеренно не удаляются вместе с ней.

Дополнительная информация о составе баз: [Data/README.md](https://github.com/Alise-Hatori/SkyrimRpEncyclopedia/blob/main/Data/README.md).
